Roni's One For All

Small, focused addons for WoW: Forever that answer the questions you keep alt-tabbing for. Where does this drop? What do I craft with it? Which alt needs these mats?

CurseForge Wago

Roni's ItemPedia

Alt + Left-Click any item: every recipe that makes or uses it, where it drops, who sells it, which quests want it, with map pins and distances.

Roni's MailMats

Open a mailbox and send each alt the reagents it can use in one click. Lockboxes to your rogue, scrolls to your mage, gear upgrades to whoever can wear them.

Install

Install Roni's One For All with the CurseForge app, WowUp or the Wago app, or download the zip from GitHub and unpack it into World of Warcraft\_forever_\Interface\AddOns. You get one folder per addon:

  • RonisItemPedia and RonisMailMats, the addons themselves.
  • RonisOneForAll, a tiny helper: type /roni in game to list what is installed and how to use each addon.

Each addon can be turned off on its own in the AddOns list on the character screen.

Recommended

Questie powers everything about mobs, vendors, spawn locations and quests in ItemPedia. Without it you still get every recipe, the item's properties and its tooltip. Auctionator adds auction prices.
